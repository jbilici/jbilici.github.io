How to calculate a rolling offset (box method, with examples)

The rolling offset formula fitters use, step by step: true offset, travel, run and cut length, with worked examples for 45° and other fittings.

A rolling offset moves a pipe both sideways (the roll) and up or down (the set) at the same time. The trick is to turn the two into one ordinary offset first, the true offset, and then use the fitting constant like a simple offset.

The formula

  1. True offset = √(roll² + set²)
  2. Travel (center to center along the angled pipe) = true offset × travel constant (1 / sin θ)
  3. Run (the advance along the line) = true offset × run constant (1 / tan θ)
  4. Cut length = travel − take-out of each fitting − weld gaps

θ is the fitting angle (45° for 45° elbows). This is the "box method" taught in apprentice programs: roll and set are two sides of the box's end, the true offset is that end's diagonal, and the run is the box's length.

Worked example: 45° fittings

Roll 12", set 16", 45° elbows.

  • True offset = √(12² + 16²) = √400 = 20"
  • Travel = 20 × 1.414 = 28.284" (28 5/16")
  • Run = 20 × 1.000 = 20"

With 2" butt-weld 45° long-radius elbows (take-out 1.38" each, ASME B16.9) and a 1/8" root gap at each weld:

  • Cut length = 28.284 − 2 × 1.38 − 2 × 0.125 = 25.274" (25 1/4")

Second example

Roll 30", set 24", 45°: true offset 38.419" (38 7/16"), travel 54.332" (54 5/16"), run 38.419".

Common mistakes

  • Assuming the run equals the true offset. Travel = √(roll² + set² + run²) is always true, but run = true offset only holds for 45° fittings. For other angles, find the true offset first and multiply by the constant for your angle.
  • Forgetting the take-outs. Travel is center to center. The pipe you cut is shorter by each fitting's take-out and the weld gaps.
  • Using the 45° take-out formula instead of the table. 1.5 × NPS × tan 22.5° is up to 1/4" short of the B16.9 table; see the butt-weld take-out chart.
  • Rounding too early. Keep three decimals until the last step, then round to the nearest 1/16".

Always verify measurements on the job before cutting.
