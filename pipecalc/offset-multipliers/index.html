Pipe offset multipliers chart (fitting constants for 11¼° to 60°)

Offset multipliers for travel, run and parallel-offset spread for 11¼°, 22½°, 30°, 45° and 60° fittings, the formulas behind them, and how to use them.

To find the travel of an offset, multiply the set (the offset) by the multiplier for your fitting angle. The same idea gives the run and the spread for parallel offsets.

Multiplier chart

Fitting angleTravel multiplier (1 / sin θ)Run multiplier (1 / tan θ)Parallel spread (tan θ/2)

22½°2.6132.4140.1989
30°2.0001.7320.2679
45°1.4141.0000.4142
60°1.1550.5770.5774

How to use it

  • Travel = set × travel multiplier
  • Run = set × run multiplier
  • Parallel offsets (equal spread): each line's starting point moves by spread × tan(θ/2). The inner line is shortened and the outer line lengthened by that amount.

Parallel offsets at 45° with 10" between lines: each line advances 10 × 0.4142 = 4.142" (4 1/8").

Why these numbers

The set, run and travel form a right triangle, with the fitting angle between the run and the travel. So set = travel × sin θ, which gives travel = set / sin θ, and run = set / tan θ. For a 45° fitting, set and run are equal.

Rolling offsets use the same multipliers after you find the true offset: see how to calculate a rolling offset.
